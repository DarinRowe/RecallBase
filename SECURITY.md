# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately by emailing the maintainers at the contact address in the repository profile, or by opening a draft security advisory on GitHub if you have access.

Please include:

- A clear description of the issue
- Steps to reproduce, if applicable
- Affected versions
- Any suggested remediation

We aim to respond within 7 days and will coordinate a fix and disclosure timeline with you.

## Scope

We are especially interested in reports involving:

- Unauthorized access to local imported history
- Leakage of raw transcripts, raw evidence, or encryption keys to the sync backend
- Bypass of the explicit-sync boundary
- Native messaging host protocol vulnerabilities
