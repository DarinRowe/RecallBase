# Web Docs

The web app is a read-only viewer for synced readable RecallBase data: search, source status, metadata, snippets, and summaries.

## Code Map

- App entry: `apps/web/src/app.tsx`
- Routes/pages: `apps/web/src/pages/*`
- API client: `apps/web/src/api/client.ts`
- Decryption helpers: `apps/web/src/api/decryption.ts`
- Search results UI: `apps/web/src/components/search-results.tsx`
